Grace Seminary - WordPress Theme
Version 1.0.0

Installation:
1. WordPress Admin > Appearance > Themes > Add New > Upload Theme.
2. Upload the ZIP and activate.
3. Create pages: About, Programmes, Admission, Contact.
4. Settings > Reading > choose a static homepage.
5. Appearance > Menus > assign Primary Menu.
6. Replace demo branding and contact details.

No premium plugin required.
